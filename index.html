Camera Integration

Connect your Reolink (or any ANPR middleman) so vehicle detections auto-log into GATEID. A small server receives the camera snapshot, reads the plate, then POSTs JSON to GATEID.

Webhook payload (what the middleman should send)

{
  "plate": "ABC1234",
  "direction": "IN",
  "siteCode": "NQ-MAIN",
  "photo": "data:image/jpeg;base64,…",
  "confidence": 0.94,
  "source": "reolink-north-gate",
  "timestamp": "2026-09-16T15:30:00Z"
}

How to wire it

  1. Reolink detects vehicle → webhook or FTP snapshot
  2. Middleman (Pi / small server) runs ANPR on the image
  3. Middleman POSTs the JSON above to your GATEID instance (or pastes into Test Injector below while testing)
  4. GATEID auto-creates a gate log entry and shows unknown-plate warnings
