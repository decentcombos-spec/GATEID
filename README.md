# GATEID v2

Professional gate identification & load tracking for quarries.

## Features
- Live camera + plate OCR + Auto Detect
- Photo captured with every log
- Weight fields: Gross / Tare / Net + Ticket #
- Unknown plate warnings (approved hauler registry)
- Edit & delete sites, trucks, logs
- Daily / shift reports (print-ready)
- Shift lock / unlock
- Print digital ticket
- Excel & CSV export
- Full JSON backup import/export (multi-device transfer)
- Offline support (service worker)
- Multi-site, multi-user roles (Admin / Operator / Viewer)
- Settings: company name, materials, default direction
