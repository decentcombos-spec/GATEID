# GATEID

Gate Identification & Load Tracking for quarries and aggregate operations.

## Features
- Live camera + license plate OCR (or manual entry)
- Auto Detect mode
- Multi-site / multi-gate
- Truck registry with auto-match
- Full gate log with search + Excel/CSV export
- User roles: Admin, Operator, Viewer
- Settings: company name, materials list, default direction
- Works offline after first load (data in browser localStorage)

## How to use
1. Open `index.html` in Safari/Chrome
2. Sign in
3. Go to **Live Gate** → Start Camera → Capture or enable Auto Detect
4. Confirm the log form → data appears in **Log** tab
5. Export Excel/CSV anytime
